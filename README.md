# The IAM Lab — Platform (`iam-lab-platform`)

Public-facing coming-soon website for **The IAM Lab** (`theiamlab.com`), an Identity and Access Management (IAM) consulting, identity security, and professional learning brand.

Delivered by **MUJTEKNIFY LIMITED**.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Linting**: ESLint (`eslint-config-next`)

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Deployment

Configured for Vercel deployment from the `main` branch with custom domain `theiamlab.com`.
